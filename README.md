One funny fortune-cookie line for an AI agent, written by a small deterministic
Python program. `main.py` (stdlib only, no network) writes the single line to
`entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`).

Entry for the [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty on make.fun.

## Run

```sh
python3 main.py
cat "$ENTRY_OUTPUT_DIR/entry.txt"
```
